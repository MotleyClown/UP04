ПРОЕКТ: HelpDesk — информационная система учёта заявок технической поддержки
Практическая работа №7 (WPF-приложение)

1. ЧТО НУЖНО ДЛЯ ЗАПУСКА
   - Visual Studio 2026 (рабочая нагрузка «Разработка классических приложений .NET»
     / .NET desktop development);
   - в Visual Studio Installer, вкладка «Отдельные компоненты», должен быть
     установлен «Пакет нацеливания .NET Framework 4.8» (Targeting Pack) —
     при необходимости добавьте его командой «Изменить»;
   - Windows 10/11.

2. КАК ОТКРЫТЬ И ЗАПУСТИТЬ
   1) Распакуйте архив в папку Учебная_практика\HelpDesk\Исходный_код.
   2) Откройте файл решения HelpDesk.sln (двойной щелчок) — решение
      открывается в Visual Studio 2026.
   3) Нажмите F5 (или кнопку «Start»).
   4) Первым открывается окно «HelpDesk — Авторизация».

3. ВРЕМЕННАЯ АВТОРИЗАЦИЯ (до подключения MS SQL Server)
   Логин:  admin
   Пароль: 12345
   При других данных появляется сообщение «Неверный логин или пароль.».

4. ЧТО УМЕЕТ ПРОГРАММА
   - Авторизация (временная, без базы данных) и переход в главное окно.
   - Главное окно: таблица заявок (DataGrid) с тестовыми данными, поиск
     по описанию (поле ввода и кнопка «Найти»), фильтр по статусу
     (Все / Новая / В работе / Выполнена / Отменена).
   - Кнопка «Добавить» — окно создания заявки (описание, категория,
     приоритет); новая заявка появляется в таблице со статусом «Новая».
   - Кнопка «Редактировать» — окно изменения заявки (описание, категория,
     приоритет, статус); изменения сразу отражаются в таблице.
   - Кнопка «Удалить» — удаление выбранной заявки с подтверждением.
   - Заявки хранятся в оперативной памяти (список List<Ticket>), поэтому
     после закрытия программы данные не сохраняются; подключение
     MS SQL Server через ADO.NET выполняется на следующих работах.

5. СТРУКТУРА ПРОЕКТА
   HelpDesk\
    ├── Views\    — окна программы (LoginWindow, MainWindow, TicketCreateWindow, TicketEditWindow)
    ├── Models\   — модели данных (User, Ticket, Category, Status, Priority)
    ├── Data\     — работа с MS SQL Server через ADO.NET (Database)
    ├── Services\ — логика функций (AuthService)
    ├── Helpers\  — вспомогательные классы (пока пустая)
    ├── App.xaml  — точка входа, StartupUri = Views/LoginWindow.xaml
    └── HelpDesk.csproj

6. ЧТО БУДЕТ ДАЛЬШЕ
   - Подключение MS SQL Server через ADO.NET (класс Database).
   - Настоящая авторизация по таблице Users (класс AuthService).
   - Хранение заявок в таблице Tickets вместо оперативной памяти.
